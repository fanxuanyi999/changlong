# 广州长隆亲子行

2026年9月24日至26日，家庭旅行手册。

在线阅读：https://fanxuanyi999.github.io/changlong/

- 三日速览：蓝黄配色路线海报。
- 每日攻略：按天切换，照片放大，地点地图链接，折叠备忘与本机核对清单。
- 行李准备：厦门出发前与酒店轻装入园两份独立勾选清单。
- Day2互动地图：12站单向路书、互斥设施图层、节点校准、区域引导与PWA离线。实现和地理数据限制见 `DAY2-MAP.md`。
- `offline.html`：图片、样式、脚本均内置，可下载离线阅读。地图与来源链接需联网。

无需构建。GitHub Pages 从 `main` 分支根目录发布。

行程信息核对日期：2026-09-20。车次编号、返程终到站和到达时间待按本人订单补齐；动态营业与设施安排以最新公告和现场为准。

照片源自长隆官方网站，版权归原权利人所有，非本次旅行实拍。详细来源见页面页脚及 `assets/credits.json`。Tabler Icons 使用 MIT 许可。本项目为家庭攻略，与景区无隶属关系。
